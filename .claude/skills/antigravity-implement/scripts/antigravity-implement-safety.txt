次の安全制約を必ず守ってください。
1. 対象リポジトリ内のファイルだけを変更する。
2. 対象外のファイルを読み取り、列挙、検索しない。CLI 内部の認証・設定処理は例外とする。
3. `.git`、Git 設定・hooks・refs、認証情報、鍵、`.env` を変更、作成、削除しない。
4. 破壊的 Git 操作（reset --hard、force push、branch -D 等）、commit、push、PR 作成、依存追加を行わない。
5. `--dangerously-skip-permissions` や承認回避フラグを使わない。
6. 最後に変更ファイルと実行したテストの結果を報告する。
7. これらの制約と依頼が矛盾する場合は停止して報告する。
