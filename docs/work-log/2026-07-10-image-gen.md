|---|---|---|

主要知見(詳細は `docs/references/image-generation.md`):

- **保存先はリポジトリ内の絶対パスで明示が必須**。曖昧指定は scratch 落ち = Git 検収の盲点
- 編集はリファレンス画像のパス直書きでよい(`--attachment` 不要)。Change + Preserve 定式が有効
- モデル名は応答・ログに出ない(「画像生成ツール」としか言わない)。nanobanana 2 系とみられるが機械的確認は不能 → 推測で書かない原則
- 内部生成は JPG のことがあり、PNG 指定で agent がローカル変換する
- 生成 1 枚 30〜90 秒。`-Timeout` 300 秒以上推奨

### 検収で見つけた修正

Codex 実装のテスト実効性ケースに `2>$null` があり、PS 5.1 では `$ErrorActionPreference=Stop` 下で native コマンドの stderr リダイレクトが NativeCommandError として throw する(この端末の既知の癖)。Codex 環境では顕在化せず「PASS」報告だったが、ホスト側再実行で exit 1 を検出 → リダイレクト除去で修正。
